# Team ticket boundary task

The task request is in instruction.md. The model starter contains only the app
and its visible regression tests under ../../environment/app.

The repository includes verification_test.rb, solution.patch and design.md for
review, with explicit user authorization. These files and the mutation
validator must remain outside the model's workspace and inference requests.
The verifier receives the hidden tests only after a model attempt completes.

See the repository's docs/team-ticket-validation-2026-10-20.md for validation
outcomes and evidence paths. All evaluation material stays out of training
corpora. This independent task is not an official Rails benchmark score.
