Letters to the editor need the same banned-words check as reader comments: a
letter whose subject or body uses one of the words should come back with
"contains words we don't publish" on that field. The check also misses
capitalised words ("Scam", "IDIOT"); it should catch them in any
capitalisation, still only as whole words ("scampi" is fine).

Keep the word list and the rule in one place. More fields will need the same
check soon (reader display names are next).
