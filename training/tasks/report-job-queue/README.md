# Choose a job's queue from its arguments

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Pass `queue_as` a block so the queue is chosen per job from its arguments.

Full credit needs a `queue_as` block. `handrolled.rb` passes the behaviour tests with overriding `queue_name`, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/ActiveJob/QueueName/ClassMethods.html
