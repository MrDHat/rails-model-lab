# Sort tickets by a business order of priorities

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Order by an explicit list of enum values with `in_order_of` instead of hand-written SQL.

Full credit needs a call to `in_order_of`. `handrolled.rb` passes the behaviour tests with a hand-written SQL CASE expression, so it gets 0.1.
