# Expose a legacy column under a clear name

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Alias the attribute so the new name works everywhere Active Record accepts attribute names.

Full credit needs an attribute alias from `email` to `emailaddr`. `handrolled.rb` passes the behaviour tests with hand-written reader and writer methods, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/ActiveModel/AttributeMethods/ClassMethods.html
