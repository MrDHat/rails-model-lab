# Update a nested profile in place

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Use `update_only` for a has_one so form data updates the existing record instead of replacing it.

Full credit needs `update_only` on the nested `profile` attributes. `handrolled.rb` passes the behaviour tests with a hand-written attributes writer, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/ActiveRecord/NestedAttributes/ClassMethods.html
