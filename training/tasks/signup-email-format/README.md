# Validate signup email shape and length

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Use the format and length validators (with Ruby's standard email pattern) rather than a hand-written check.

Full credit needs format and length validators on `email`. `handrolled.rb` passes the behaviour tests with a custom validation method, so it gets 0.1.

Written from these public references:

- https://guides.rubyonrails.org/active_record_validations.html
- https://docs.ruby-lang.org/en/3.4/URI/MailTo.html
