# Give new tickets a default priority

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Declare the default on the attribute so only new records get it and it's persisted, without changing the schema.

Full credit needs a declared attribute default of 3 for `priority`. `handrolled.rb` passes the behaviour tests with an `after_initialize` callback, so it gets 0.1.

Written from these public references:
