# Store and check passwords safely

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Use `has_secure_password` for hashing, confirmation and authentication.

Full credit needs `has_secure_password` on the model. `handrolled.rb` passes the behaviour tests with hand-written BCrypt methods and validations, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/ActiveModel/SecurePassword/ClassMethods.html
