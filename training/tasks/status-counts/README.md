# Count rows per status in the database

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Let the database group and count with `group(...).count` instead of loading records into Ruby.

Full credit needs calls to `group` and `count`. `handrolled.rb` passes the behaviour tests with raw SQL with GROUP BY, so it gets 0.1.

Written from these public references:

- https://guides.rubyonrails.org/active_record_querying.html
