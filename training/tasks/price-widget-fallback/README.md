# Show a fallback and report the error

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Use the error reporter's `handle`, which reports the error to subscribers and returns a fallback.

Full credit needs a call to `handle` on the error reporter. `handrolled.rb` passes the behaviour tests with a rescue that calls `report`, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/ActiveSupport/ErrorReporter.html
- https://guides.rubyonrails.org/error_reporting.html
