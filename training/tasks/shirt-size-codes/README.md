# Map shirt sizes to one-letter codes

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Use an enum with string values to map names to stored codes, which also gives predicates and scopes.

Full credit needs an enum for `size`. `handrolled.rb` passes the behaviour tests with constants plus hand-written scopes, predicates and accessors, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/ActiveRecord/Enum.html
