# Get the Monday-to-Sunday week around a date

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Use `all_week(:monday)` or `beginning_of_week(:monday)` instead of weekday arithmetic.

Full credit needs `all_week` or `beginning_of_week`. `handrolled.rb` passes the behaviour tests with arithmetic on `cwday`, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/DateAndTime/Calculations.html
