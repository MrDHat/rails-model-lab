# Join names into a readable list

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Use `Array#to_sentence` rather than writing the joining rules by hand.

Full credit needs a call to `to_sentence`. `handrolled.rb` passes the behaviour tests with a hand-written case on the list size, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/Array.html
