# Describe a number of seconds in words

One Rails exercise. It is not from the benchmark and is not training data until
training is separately approved. See [the task format](../../README.md).

Build an `ActiveSupport::Duration` from the seconds and let it split and describe the parts.

Full credit needs `ActiveSupport::Duration.build`. `handrolled.rb` passes the behaviour tests with hand-written divmod and pluralisation, so it gets 0.1.

Written from these public references:

- https://api.rubyonrails.org/v8.1.3/classes/ActiveSupport/Duration.html
