# Separate local MLX inference variant

The Mac's Apple M1 / 16 GiB configuration can run a short, offline diagnostic
with `mlx-community/Qwen3.5-4B-4bit`, pinned to
`0e7ffd5c629ef7719d4cbc04069232580bfa9d9c`. This is a community 4-bit
conversion, not the Colab float16 checkpoint. Its upstream base commit is
unknown; do not attribute its results to the pinned Colab base revision or
treat backend differences as training improvements. No training occurred.

The packages are isolated under ignored `runs/mlx-runtime/venv`;
`experiments/mlx-requirements.txt` freezes the installed versions. Model weights
and tokenizer files were downloaded anonymously from the pinned public Hub
snapshot into `runs/mlx-runtime/hf`. The download plan records 3,061,130,647
bytes. No account token, remote Python code, external inference endpoint, or
system memory setting is used. Inference loads the local snapshot with
`trust_remote_code=False`, Hub and Transformers offline mode enabled.

## Non-task evidence

`runs/mlx-runtime/smoke.json`: exact `OK`, 17 input / 2 output tokens,
5.457 generation seconds, 2.328 GiB peak unified-memory allocation. It stopped
on tokenizer end-of-turn 248046 rather than the model config's 248044.

`runs/mlx-live-relay-check`: a fresh exact-OK request passed through the Ruby
file provider and produced a consumption receipt. A separate native bash-tool
probe produced one parsed `echo OK` call: 282 input / 27 output tokens,
17.442 seconds, 2.810 GiB peak unified memory. That diagnostic command was not
executed. These are transport/inference checks, not task scores.

Five worker fixtures cover context/runtime rejection, unchanged request bytes,
native tool parsing, truncation, expiry quarantine, and duplicate delivery.
Ten report fixtures pass, including separate unified-memory and CUDA fields.

## Local development protocol

`bash bin/run-mlx-development` selects the team-ticket task by default. Its
independent fixed protocol uses 32 steps, 16,384 input / 2,048 output tokens,
greedy decoding, thinking disabled, prefill steps of 1,024, 30-minute agent and
600-second response deadlines. Miniswen, the starter, and grader are unchanged.
This short smoke check does not prove every maximum-length request fits memory
or finishes within its deadline; failures remain unscored infrastructure errors.

The runner freezes evaluation inputs, hashes model files, snapshots transport
sources and both dependency locks, and starts a local worker that is stopped
on harness exit. Docker receives only the starter app. Hidden tests, reference
patches and mutation fixtures remain outside the model workspace. All task
requests, generations and execution output remain on the Mac; this does not
use the pending team-ticket Colab authorization. All evaluation evidence stays
out of training data.

The setup leaves roughly 4 GiB free disk after the smoke test. Reuse cached
Docker images and downloaded weights; avoid further large downloads here.
